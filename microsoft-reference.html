Solution Architect Decision Guide

1. Compute — VMs (control) · AKS/Container Apps (containers) · Functions (serverless) · App Service (web) · Batch (jobs)

2. Storage — Blob (objects) · Managed Disks (block) · Azure Files (SMB/NFS) · NetApp Files (enterprise) · Archive (cold)

3. Database — SQL Database/Managed Instance (SQL) · Cosmos DB (NoSQL) · PostgreSQL/MySQL (open source) · Redis Cache (in-memory)

4. Network — VNet · Azure DNS · Load Balancer/App Gateway · Front Door · ExpressRoute/VPN

5. Security — Entra ID · Key Vault · Defender for Cloud · Sentinel · Firewall/WAF · DDoS Protection

6. Observability — Azure Monitor · Log Analytics · Application Insights · Service Health

7. Governance — Azure Policy · Blueprints · Cost Management · ARM Templates

8. Integration — Service Bus · Event Grid · Event Hubs · Logic Apps · API Management

9. Migration — Azure Migrate · Site Recovery (DR) · DMS (databases) · Data Box / Storage Mover

10. AI / ML — Azure OpenAI · AI Services · Machine Learning · AI Search · Microsoft Foundry

Serverless variant: Front Door → API Management → Functions → Cosmos DB, with Event Grid/Service Bus for async and Logic Apps for workflow.

Data/ML variant: Sources → Event Hubs → Data Lake → Data Factory → Synapse/Databricks → Azure ML / Azure OpenAI → Power BI.

How to read this reference

  • Definition — plain-language description of what the service is and does.
  • Use case — the shortest tag for the primary job.
  • When to choose — trigger conditions that push you toward this service.
  • Fit — S/M/L boxes ticked = natural fit at that org size.
  • Cost — LOW = pennies to low hundreds; MED = hundreds to low thousands; HIGH = thousands+ or committed capacity. Actual spend is workload-dependent.
  • Services with * are deprecated or being retired.

Why Azure?

  • 200+ services across 20+ categories
  • 60+ regions, more than any other cloud provider
  • Hybrid advantage: Arc, Stack, Local, ExpressRoute
  • Deep Microsoft integration: Entra ID, Microsoft 365, Dynamics 365
  • Enterprise AI: Azure OpenAI Service, AI Services, Microsoft Foundry
  • Best-in-class enterprise compliance and governance
