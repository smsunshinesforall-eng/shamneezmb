# HTML Project Collection

This repository contains 18 latest recoverable HTML project versions, plus an `index.html` launcher.

## GitHub Pages
Go to **Settings → Pages**, choose **Deploy from a branch**, select your default branch and `/ (root)`, then save. The main `index.html` serves as your landing page.

## Notes
- Earlier revisions, duplicate source uploads, and superseded form versions were excluded.
- Standalone HTML contents are retained without modification. Some projects may require external internet resources.
- This reflects recoverable files rather than an exhaustive audit of every historical chat.
